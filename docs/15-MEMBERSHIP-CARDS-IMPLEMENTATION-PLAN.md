# 用户会员功能说明

状态：用户端购买、服务端扣款和订单计费已实现。

## 业务规则

- 月卡 648 元，有效期 30 天；季卡 999 元，有效期 90 天。
- 购买使用钱包余额，余额不足或账号冻结时不能购买。
- 重复购买按当前到期时间继续延长；已过期则从购买时间开始计算。
- 有效会员的服务费按八折计算，基础电价不打折。
- 优惠券与会员可以同时使用：先计算会员服务费，再对订单总金额使用八折券。
- 订单创建时保存价格和折扣结果，会员后来到期不会改变已有订单。

## 数据与接口

`user` 保存会员状态、剩余天数、到期时间和服务费折扣；`membership_product`
保存月卡和季卡；`membership_purchase` 保存购买记录。余额扣减、会员更新和购买记录
在同一事务完成。

| 接口 | 作用 |
| --- | --- |
| `MEMBERSHIP_PRODUCT_LIST` | 查询在售会员卡 |
| `MEMBERSHIP_STATUS_GET` | 查询当前会员状态 |
| `MEMBERSHIP_PURCHASE` | 根据 `productNo` 购买或续期 |

会员中心从服务端读取产品名称、价格、有效期和折扣。购买成功后刷新钱包余额及会员状态。
