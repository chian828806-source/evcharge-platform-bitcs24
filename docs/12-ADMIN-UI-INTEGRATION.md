# Qt 管理端 UI 与接口对接需求 V1.0

状态：已确定（管理端前端实现依据）  
适用范围：`qt-admin` 管理员界面  
最后更新：2026-09-03

## 1. 对接目标

本文规定管理端 UI 必须提供的页面、控件、布局和接口入口。前端同学可调整视觉样式，
但不得删除本文标为必做的内容，也不要增加 V1 未支持的操作按钮。

管理端共 5 个页面：

| 编号 | 页面 | 必做内容 |
| --- | --- | --- |
| A01 | 管理员登录 | 账号密码登录、连接和错误提示 |
| A02 | 运营概览 | 营收卡片、7/30 日趋势、电桩状态、负荷预警 |
| A03 | 电桩管理 | 电桩表格、站点筛选、远程重启 |
| A04 | 充电站管理 | 站点表格、新增站点、查看站内电桩 |
| A05 | 用户管理 | 手机号搜索、用户表格、冻结/解冻 |

## 2. 已确定的 UI 方案

以下方案直接作为实现要求，不再保留待确认项。

| ID | UI 要求 | 确定方案 | 接口影响 |
| --- | --- | --- | --- |
| UI-A01 | 登录连接设置 | 演示时默认隐藏服务器地址和端口，放在可展开的“连接设置”中 | 不改接口 |
| UI-A02 | 断线和 Session 失效 | 自动回登录页，保留服务器地址，清空密码 | 重新登录 |
| UI-A03 | Dashboard 布局 | 上方三张营收卡片；中间趋势图和明细；下方状态图与预警列表 | 同时请求 4 类数据 |
| UI-A04 | 负荷预警 | 放在 Dashboard，提供 1h/6h/24h 三个切换按钮，默认 1h | `PREDICTION_WARNING` |
| UI-A05 | 站内电桩详情 | 站点列表在左，站内电桩详情在右，不跳转页面 | `ADMIN_PILE_LIST` |
| UI-A06 | 新增站点电价 | 必须输入充电单价，默认 1.20 元/度 | 发送 `priceFenPerKwh` |
| UI-A07 | 危险操作 | 重启、冻结、解冻都显示二次确认 | 接口不变 |
| UI-A08 | 表格数据量 | V1 不分页，使用滚动；用户页保留手机号搜索 | 当前接口不支持分页 |
| UI-A09 | 状态显示 | 使用第 4.2 节固定的中文和颜色映射 | 接口仍返回英文枚举 |
| UI-A10 | 操作反馈 | 成功显示轻提示；失败和危险操作使用弹窗；请求期间禁用按钮 | 使用 `code/message` |

## 3. 各页面需要预留的控件和接口

### A01 管理员登录

| UI 区域 | 控件/状态 | 调用或数据 |
| --- | --- | --- |
| 登录表单 | 账号输入框 | `username` |
| 登录表单 | 密码输入框、回车登录 | `password` |
| 登录表单 | 登录按钮及“正在登录”状态 | `ADMIN_LOGIN` |
| 连接设置 | 服务端地址、端口 | `AdminSocketClient::connectToServer` |
| 提示区 | 账号错误、网络错误、超时 | `code/message` 或客户端错误 |
| 登录后 | 管理员名称、退出入口 | `admin.displayName`；退出为本地清理 Session |

登录后顶部必须显示管理员名称和退出按钮。退出时清空 Session 并返回登录页。

### A02 运营概览

| UI 区域 | 控件/内容 | 调用或字段 |
| --- | --- | --- |
| 顶部 | 手动刷新、最后更新时间 | 同时刷新本页接口 |
| 指标卡片 | 今日、本月、累计营收 | `ADMIN_REVENUE_SUMMARY` |
| 趋势图 | 7 日/30 日切换 | `ADMIN_REVENUE_TREND { days }` |
| 趋势图 | 日期、营收、充电量和订单数三组数据 | `points[]` |
| 状态图 | 各电桩状态数量和占比 | `ADMIN_PILE_STATUS_SUMMARY` |
| 预警区 | 预测时间、站点、负荷率、预计空闲数、峰值等级 | `PREDICTION_WARNING` |

固定布局：

```text
┌ 今日营收 ┐ ┌ 本月营收 ┐ ┌ 累计营收 ┐
┌────────── 7/30 日营收趋势 ──────────┐
┌──── 电桩状态图 ────┐ ┌── 负荷预警列表 ──┐
```

趋势图必须使用 `date` 作为横轴，并展示营收、充电量和订单数。图表下方保留每日明细表，
避免不同单位的曲线不易读取。

### A03 电桩管理

| UI 区域 | 控件/内容 | 调用或字段 |
| --- | --- | --- |
| 筛选区 | 当前站点、清除筛选、刷新 | `ADMIN_PILE_LIST`，可选 `stationId` |
| 表格 | 桩号、站点、类型、功率、状态、次数、累计分钟 | `piles[]` |
| 操作列 | 远程重启按钮 | `ADMIN_PILE_RESTART { pileId }` |
| 弹窗/提示 | 重启确认、提交中、成功/失败 | 响应 `code/message` |

按钮规则：预约中、充电中和重启中的电桩不能重启。重启成功后先显示“重启中”，随后
自动刷新最终状态。

增加本地状态筛选，下拉选项为“全部”和第 4.2 节中的电桩状态，不修改后端接口。

### A04 充电站管理

| UI 区域 | 控件/内容 | 调用或字段 |
| --- | --- | --- |
| 顶部 | 新增站点、刷新 | `ADMIN_STATION_CREATE` / `ADMIN_STATION_LIST` |
| 表格 | 编号、名称、地址、经纬度、电桩数、在线率 | `stations[]` |
| 操作列 | 查看电桩 | `ADMIN_PILE_LIST { stationId }` |
| 新增弹窗 | 站名、地址、经纬度、电桩数量 | 必填请求字段 |
| 新增弹窗 | 充电单价，默认 1.20 元/度 | 必填 `priceFenPerKwh` |

表单需要进行基本检查：站名和地址不能为空，经度为 -180～180，纬度为 -90～90，
电桩数量为 1～100。点击确认后禁用按钮，等待成功或失败结果。

### A05 用户管理

| UI 区域 | 控件/内容 | 调用或字段 |
| --- | --- | --- |
| 查询区 | 手机号关键词、查询、清空 | `ADMIN_USER_LIST { phoneKeyword }` |
| 表格 | ID、手机号、昵称、余额、注册时间、状态 | `users[]` |
| 操作列 | 冻结或解冻 | `ADMIN_USER_FREEZE` / `ADMIN_USER_UNFREEZE` |
| 弹窗/提示 | 确认、提交中、成功/失败 | `code/message`、`changed` |

冻结确认弹窗必须提示“冻结后该用户不能登录和进行业务操作”，并显示用户手机号。

## 4. UI 统一状态和文案

### 4.1 每块数据都要有四种状态

```text
加载中 / 有数据 / 暂无数据 / 加载失败
```

Dashboard 的多个接口相互独立。例如趋势加载失败时，营收卡片和状态图仍应正常显示。

### 4.2 固定的状态显示

| 接口值 | 中文显示 | 颜色 |
| --- | --- | --- |
| `AVAILABLE` | 空闲 | 绿色 |
| `RESERVED` | 已预约 | 蓝色 |
| `CHARGING` | 充电中 | 蓝色或橙色 |
| `FAULT` | 故障 | 红色 |
| `OFFLINE` | 离线 | 灰色 |
| `RESTARTING` | 重启中 | 橙色 |
| `NORMAL` | 正常 | 绿色 |
| `FROZEN` | 已冻结 | 红色或灰色 |

颜色深浅可随整体主题微调，但不同状态的基本色和中文含义保持不变。

### 4.3 金额、时间和比例

- `*Fen` 从分转换为元，显示两位小数；
- `powerKw` 显示单位 kW；
- `energyKwh` 显示单位 kWh；
- `onlineRate` 和 `ratio` 是 0～1，界面转为百分比；
- `totalChargeMinutes` 小于 60 时显示分钟，达到 60 后显示“小时 + 分钟”；
- 时间统一显示为 `yyyy-MM-dd HH:mm`，原始值不直接展示给用户。

## 6. V1 暂不预留

V1 管理端 UI 不加入：

- 用户端的任何页面或接口；
- 修改、删除充电站；
- 新增、编辑、删除单个电桩；
- 用户昵称搜索、状态筛选和分页；
- 管理员账号管理和修改密码；
- 操作日志页面；
- 导出 Excel、打印报表；
- 真实设备控制。

这些控件如果先画进 UI，会让使用者误以为后端已经支持，因此暂时不要放置。
