# 20. 第二阶段大数据需求规格（SRS）

## 1. 目标与边界

第二阶段在一期新能源汽车充电业务模型上建立离线大数据分析平台：生成/导入可追溯数据，完成
HDFS 存储、PySpark 质量治理、SparkSQL 四层数仓、Flask 分析 API、Vue + ECharts 大屏和
Spark MLlib 负荷预测。SQLite 仍是一期业务权威库，Qt/C++ 服务端仍是唯一业务写入方。

不在范围内：重写 Qt User、Qt Admin、Qt/C++ Server、Device Simulator 或一期核心订单流程；
删除一期 `ml/` 的 sklearn baseline；让 Flask 直接承担一期业务事务；让 Vue 直接访问 SQLite。

## 2. 功能需求

| ID | 需求 | 最低可验证结果 |
| --- | --- | --- |
| BD-FR-001 | Hadoop/HDFS 数据存储 | ODS 文件按日期分区可列举、可读取 |
| BD-FR-002 | 基于一期实体生成模拟数据 | 固定种子生成站点、电桩、订单、会话等 CSV |
| BD-FR-003 | 注入数据质量问题 | 输出注入清单，含空值、重复、异常、逻辑/枚举/引用错误 |
| BD-FR-004 | PySpark 质量检测 | 按 `DQ-*` 规则输出问题数和拒绝原因 |
| BD-FR-005 | PySpark 清洗 | 合法记录进入 DWD，异常记录可追溯 |
| BD-FR-006 | ODS-DWD-DWS-ADS 数仓 | 每层有表、粒度、主键、分区和血缘 |
| BD-FR-007 | SparkSQL 多维分析 | 站点、区域、时段、营收、电量、利用率统计可复跑 |
| BD-FR-008 | Flask REST 服务 | 9 个冻结端点符合 24 号文档 |
| BD-FR-009 | Vue3 + ECharts 大屏 | 以 API 展示 KPI、趋势、排行、状态、热力与预测 |
| BD-FR-010 | Spark MLlib 预测 | 对 `1h/6h/24h` 输出负荷、可用桩和峰值等级 |
| BD-FR-011 | 数据质量报告 | 有输入批次、规则、问题数、处置和前后对比 |
| BD-FR-012 | 模型评价 | 时间切分并输出 RMSE、MAE、R² 和基线对比 |
| BD-FR-013 | 全链路演示 | 一条命令/清单能从输入批次走到 API 与大屏 |

## 3. 非功能要求

- 可复现：生成器、ETL 与训练均记录版本、随机种子、批次和时间。
- 可追溯：任何 ADS 结果能回溯至 DWS/DWD/ODS 批次；拒绝数据保留原因。
- 契约优先：跨模块仅通过本文档集定义的文件、表与 HTTP 接口协作。
- 演示安全：不提交凭据、生产数据或一期 SQLite 副本；大数据运行产物可重建。
