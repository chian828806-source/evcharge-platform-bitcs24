# shared — 跨端公共代码

本目录保存 Qt 用户端和 Qt 服务端共同使用的代码。它不是一个独立运行的服务，也不包含订单、充值等业务规则。

## 子目录

| 目录 | 功能 |
| --- | --- |
| protocol | Socket公共消息、错误码和JSON Lines编解码 |

## 使用原则

1. 两端必须复用这里的消息名称和封装，禁止各写一套字符串。
2. 这里只描述“消息长什么样”，不访问数据库，也不操作界面。
3. 公共契约来源是 docs/03-API.md；文档未确认的字段不能自行加入。
4. 修改本目录会同时影响客户端和服务端，必须重新编译两端及协议测试。
